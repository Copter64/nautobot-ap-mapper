# Using the App

This document describes common use-cases and scenarios for this App.

## General Usage

AP Mapper is designed for wireless network planning and troubleshooting. The core workflow is:

1. Upload a floor plan image for a location
2. Place access points and devices on the map
3. Use the visual layout to plan coverage, troubleshoot issues, or document the network

## Use-cases and common workflows

### Wireless AP Coverage Planning

Before deploying new access points, upload the floor plan and place candidate AP locations. Use different colors to show coverage overlap or gaps. Once deployed, update the placements to match actual positions.

### Physical Inventory Documentation

Place all devices (switches, racks, APs) on the floor plan to create a visual inventory. This helps field technicians quickly locate equipment during maintenance or troubleshooting.

### Multi-Floor Site Mapping

Create a separate floor plan for each floor/location in a building. Use the Location hierarchy to organize them (e.g., Building A → Floor 1, Floor 2, etc.). Each floor plan is independent but linked to its location.

### API-Driven Automation

Use the REST API to sync AP placements from external systems (e.g., network inventory tools, building management systems). This keeps the maps up-to-date without manual intervention.

### Troubleshooting RF Issues

When investigating RF interference or coverage issues, open the relevant floor plan and review AP placements. The visual layout helps identify APs that may be too close together or in poor positions.
